# 演示场景清单

共 56 个。运行 `cargo run -p loom-app -- --demo`(或 `scripts/dev.sh --demo`)进入演示模式。

## 怎么看某个场景

- **⌘K 命令面板 → 搜场景名(分组「演示场景」)**:选中后从头按演示速度实时播放(已打开的会先关掉再重播)。
- **重新播放**:命令面板「演示:重新播放当前场景」。
- **调速度**:命令面板「演示速度:正常 ×1 / 慢 ×3(默认)/ 很慢 ×6 / 极慢 ×12」,下次播放生效;也可用环境变量 `LOOM_DEMO_SLOW=6` 设启动时的初值。
- **在任意会话里**输入 `/demo-<场景id>` 回车,也会播放该场景。
- 侧栏里点场景会话:历史会话**瞬时回放**(直接看到最终样子),只有 showcase-tour / thinking-time / showcase-all / bg-* 默认实时播放;其余场景放在 `scenario-lab` 项目里。
- 截图用:`LOOM_SESSION=<场景id> scripts/shots.sh <场景id>`。
